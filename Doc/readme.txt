【*】 程序简介

-工程名称：F407 四轴步进电机控制（两组同步 + 梯形加减速）
-实验平台：野火 STM32 F407 骄阳电机开发板 + 电机板
-源码位置：..\User\ 与 ..\Project\
-说明：本工程基于野火官方例程《步进电机--梯形加减速实现》修改而来，改动较多
        （4 个电机分两组同步、5 个按键 + 电阻触摸屏界面）。
        更完整的说明请看仓库根目录的 README.md。

【 ！】功能简介：

1. 四个步进电机分成两组：电机 1+2 = 轴1，电机 3+4 = 轴2；
   同一组的两个电机由同一套状态机驱动，脉冲完全同步，不会跑偏。
2. 梯形加减速：加速 -> 匀速 -> 减速，由 TIM8 比较中断里的状态机实时计算。
3. 操作方式两套，功能完全等价：
   - 5 个物理按键（KEY1 ~ KEY5）
   - 屏幕上的 5 个按钮（UNIT / - / + / MODE / RUN）
4. 距离单位三档循环切换：10cm -> 1cm -> 1mm；距离可正可负，负值就是反方向。
5. 屏幕上实时显示：要走的距离、单位、当前模式、运行状态、已发脉冲数。

【 ！】实验操作：

1. 下载本程序，复位开发板；
2. 上电默认模式 0（电机 1、2），LED1 亮；
3. KEY2 切换模式（LED1 / LED2 指示当前控制哪一组）；
4. KEY3 切换单位，KEY5 / KEY4 按当前单位加 / 减距离；
5. KEY1 让当前那一组走一次；
6. 触摸屏操作与上面完全一样。

【 ！！】注意事项：

1. 步进电机驱动器使用 32 细分，必须和代码里的 MICRO_STEP 一致（当前 32）。
2. 一个脉冲 = 一个细分步：200 步/圈 x 32 细分 = 6400 脉冲/圈。
3. 距离换算：脉冲数 = 距离(mm) x 6400 / 每圈毫米数（Screw_Lead12 / Screw_Lead34）。
4. 速度与加减速参数在 User\main.c 顶部（set_speed / accel_val / decel_val），
   调大之后要重新确认不丢步。
5. 某个电机方向反了，改 User\stepper\bsp_stepper_init.h 里的 MOTORx_DIR_REVERSE，
   不用改接线。
6. 源码是 GBK 编码，用其它编辑器改完请另存为 ANSI / GBK。

【*】 接线

串口（TTL-USB TO UART）：
CH340的收发引脚与STM32的发收引脚相连。
	RX <---> PB6
	TX <---> PB7
（USART1，115200 8-N-1。注意：当前 main.c 里 DEBUG_USART_Config() 被注释掉了，串口暂未启用）

步进电机驱动器接口1：
	PUL+ <---> VCOM
	PUL- <---> PI5    (TIM8_CH1)
	DIR+ <---> VCOM
	DIR- <---> PE1
	ENA+ <---> VCOM
	ENA- <---> PE0

步进电机驱动器接口2：
	PUL- <---> PI6    (TIM8_CH2)
	DIR- <---> PI8
	ENA- <---> PE4

步进电机驱动器接口3：
	PUL- <---> PI7    (TIM8_CH3)
	DIR- <---> PI11
	ENA- <---> PI10

步进电机驱动器接口4：
	PUL- <---> PC9    (TIM8_CH4)
	DIR- <---> PF2
	ENA- <---> PF1

按键：
	KEY1 = PA0    走一次
	KEY2 = PG2    切换模式（电机1、2 / 电机3、4）
	KEY3 = PC13   切换单位（10cm / 1cm / 1mm）
	KEY4 = PG3    按当前单位减
	KEY5 = PG4    按当前单位加

LED：
	LED1 = PA15   亮 = 模式0（控制电机1、2）
	LED2 = PE2    亮 = 模式1（控制电机3、4）

LCD / 触摸：
	屏幕：FSMC 8080 接口，NE3 作片选、A0 作 RS；复位 PF11，背光 PE5
	触摸：XPT2046，软件模拟 SPI；CLK=PG9  CS=PH4  MOSI=PD6  MISO=PH5  PENIRQ=PG8

【*】 时钟

A.晶振：
-外部高速晶振：25MHz
-RTC晶振：32.768KHz

B.各总线运行时钟：
-系统时钟 = SYSCLK = AHB1 = 168MHz
-APB2 = 84MHz
-APB1 = 42MHz

C.浮点运算单元：
  使用（工程里 Cortex-M4 的 FPU 已使能；速度换算和梯形加减速都用到了浮点）
  注：原例程文档写的是“不使用”，当前工程已经改掉了。

D.TIM8（发脉冲的定时器）：
-TIM8 挂在 APB2 上，168MHz；TIM_PRESCALER = 28 -> 计数频率 6MHz
-速度公式里的 T1_FREQ 与它完全一致，算出来的速度才准

【*】 与官方例程的主要差异

1. 一个电机 -> 四个电机，两两同步成两组（轴 AXIS_12 / AXIS_34）。
2. 脉冲由 TIM8 四通道输出，一个中断（TIM8_CC_IRQHandler）驱动两个轴：
   节拍通道（CH1/CH3）产生中断，跟随通道（CH2/CH4）写同样的比较值，两路同时翻转。
3. 新增电阻触摸屏（XPT2046）和 LCD 界面（bsp_ui.c），按键与触摸共用 DoAction()。
4. HAL_Delay 改为基于 DWT 计数（core_delay.c 重写了 HAL_InitTick），
   让 SysTick 中断不参与，避免影响 TIM8 的脉冲节拍。
5. TIM_PRESCALER 由 5 改为 28：原例程初始化写 5，而速度公式按 28MHz 计算，
   两边差 20%（实际速度比设定值快两成）；改成 28 后两边都是 6MHz。
